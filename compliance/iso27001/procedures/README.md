# Procedures

Implementation baselines now cover incident response/evidence handling,
privileged access and break glass, service credentials, property access, and
backup restoration. These drafts are not operating evidence: management must
approve named roles/channels, and Operations must execute the live tests.

Additional readiness drafts now cover retention/deletion, supplier review,
secure development/change, upload quarantine, protected logging, awareness,
Finance/payment controls and property-access drills. Approval and completed live
records remain required. Full HR joiner/mover/leaver and vulnerability-response
procedures remain part of the P1 human/legal workstream.
